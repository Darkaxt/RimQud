# Third-party materials and provenance

RimQud is an independent research project, unaffiliated with the games' creators.
The MIT license applies only to original project code and documentation, and
does not grant rights to any third-party game material.

- **Caves of Qud / Freehold Games:** original glyph/tile appearances visible in
  comparison screenshots and the installed runtime used for the probe.
- **RimWorld / Ludeon Studios:** shader names, resource metadata and terrain,
  plants, body/head, cat and furniture content visible in contextual engine
  readbacks. No raw donor
  textures, compiled shader records, bundles, assemblies or decompiled game source
  are distributed in this repository.
- **Stoneshard / Ink Stains Games:** an art-direction reference for one original
  AI-generated concept sheet. The sheet is not an extracted Stoneshard tileset.
- **Vehicle Framework, Steam Workshop item 3014915404:** its installed
  `1.6/AssetBundles/shaders_win` provided the container/type-tree template for the
  private packaging experiment. The template bundle is not distributed here.
- **UnityPy 1.25.4, Pillow, Harmony, Newtonsoft.Json and Unity:** external tools or
  runtime dependencies, not vendored in this repository. Their own licenses apply.

content/mod is not official and is not endorsed by Ludeon.

The original generated sprite sheets were created with the image-generation tool
for the earlier local study. Comparison screenshots combine these sheets with
Qud's original presentation. The small engine-test images are contextual rendered
evidence, not a replacement asset pack. Exact file provenance and SHA-256 hashes
are recorded in [the image manifest](docs/images/provenance.json).
